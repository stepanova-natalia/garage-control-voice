# Garage Voice Assistant

Голосовой помощник для управления гаражом. Работает офлайн, все данные хранятся на домашнем сервере.

## Возможности

- Управление воротами голосом — открыть, закрыть, остановить, продолжить
- Управление светом — включить, выключить
- Запрос статуса ворот и света
- Оповещение о смене статуса ворот в реальном времени через WebSocket
- Работает полностью локально — без облака

## Команды

Для активации скажите «Окей Джарвис» (или имя которое вы задали в настройках).

| Команда | Действие |
|---|---|
| Окей Джарвис, открой ворота | Открыть ворота |
| Окей Джарвис, закрой ворота | Закрыть ворота |
| Окей Джарвис, останови ворота | Остановить ворота во время движения |
| Окей Джарвис, продолжи движение | Продолжить движение ворот |
| Окей Джарвис, статус ворот | Узнать статус ворот |
| Окей Джарвис, включи свет | Включить свет |
| Окей Джарвис, выключи свет | Выключить свет |
| Окей Джарвис, статус света | Узнать статус света |

## Требования

- Android 8.0 (API 26) и выше
- Домашний сервер с запущенным Garage Backend
- Подключение к домашней WiFi сети или VPN

## Настройка

1. Установите APK на телефон
2. При первом запуске войдите с вашими учётными данными
3. В настройках (шестерёнка) укажите URL сервера — например `https://garage.home.arpa`
4. Там же можно изменить имя помощника

## Архитектура

```
Телефон:
  Vosk (офлайн распознавание речи)
  VoiceSession (машина состояний)
  CommandRegistry (реестр обработчиков команд)
  GateCommandHandler / LightCommandHandler

Домашний сервер:
  Ktor REST API
  MQTT → ESP8266 → реле → ворота/свет
  WebSocket → статус в реальном времени
```

## Технический стек

- Kotlin + Jetpack Compose
- Hilt — dependency injection
- Vosk — офлайн распознавание речи
- Retrofit + OkHttp — REST API
- WebSocket — статус ворот в реальном времени
- JWT аутентификация

## Технический долг

- Porcupine или Sherpa-onnx — wake word вместо Vosk
- Whisper на сервере — более точное распознавание речи
- WireGuard split tunneling — корректная работа VPN в домашней сети
- Silero TTS — лучший голос помощника
- Энкодер KY-040 — определение движения ворот
